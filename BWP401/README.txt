مشروع BWP401: دليل فعاليات الجامعة الافتراضية السورية
إعداد: دانا عبيد | الرقم الجامعي: dana_341670

محتويات الموقع:
- index.html: الصفحة الرئيسية واسم الطالبة ورقمها الجامعي
- events.html: عرض الفعاليات والبحث والتصفية حسب التصنيف والتاريخ
- event.html: تفاصيل الفعالية مع مشاركة/إضافة إلى التقويم
- about.html: نبذة عن الدليل وفريق العمل
- contact.html: نموذج تواصل مع تحقق من المدخلات ورسائل نجاح/خطأ
- assets/css/styles.css: تنسيق متجاوب مخصص
- assets/js/main.js: تفاعلات JavaScript
- assets/img/: رسوم توضيحية محلية للفعاليات

التقنيات: HTML5 وCSS وJavaScript وBootstrap RTL 5.3.3.
افتح index.html في المتصفح لمعاينة الموقع. يعتمد Bootstrap على CDN، لذلك يلزم اتصال بالإنترنت لتحميله.

مهم قبل التسليم: الفعاليات المعروضة أمثلة تعليمية وليست تأكيداً لفعاليات حقيقية. أضيفوا أسماء وأرقام بقية أعضاء المجموعة إن كان المشروع جماعياً. اختبروا الموقع على الهاتف والحاسوب، ثم ارفعوه إلى استضافة مجانية مثل GitHub Pages، وأرسلوا رابط الاستضافة إلى t_balkhatib@svuonline.org بعنوان BWP401 HW مع جميع الأرقام الجامعية، وارفعوا ملف ZIP على Moodle وفق تعليمات الوظيفة.
